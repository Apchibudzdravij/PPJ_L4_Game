# PPJ_L4_Game

A small game that works in the terminal, single .java file, single class and function.

---

The Player can type any numbers, word or sentences, but only "1",  "2" and Enter are expected inputs. Entering anything else may make me angry on several screens!

## Installation/Run

You can either download the precompiled build from [Releases](https://github.com/Apchibudzdravij/PPJ_L4_Game/releases) or clone this repository. After cloning you can compile and run the project using the following commands:

``` bash
	javac L4Game.java
	java L4Game
```

It is also possible to run it with the next command:

``` bash
	java L4Game.java
```
